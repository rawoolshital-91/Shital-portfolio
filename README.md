# Personal Portfolio Website

A personal portfolio website built using Flask, HTML, CSS, and SQLite.

## Features

- Responsive portfolio design
- Skills showcase
- Project showcase
- Resume download
- Contact form
- SQLite database integration

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure

├── app.py
├── requirements.txt
├── portfolio.db
├── static/
└── templates/
